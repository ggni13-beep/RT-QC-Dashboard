① 使用呼吸器病人收案之完整性

追蹤 Redcap 收案紀錄與臨床系統狀態的一致性

📝 PLAN｜問題確認

發現部分病人於臨床系統已進行狀態設定， 但 Redcap 收案或相關紀錄未同步更新， 造成品質指標未達標。

  • 系統間狀態未同步
  • 狀態異動後未即時更新
  • 缺乏一致性的確認流程
🎯 改善目標：提升收案完整性與紀錄一致性

🚀 DO｜改善措施

  • 宣導狀態異動後同步確認 Redcap
  • 由 QC 組員進行例行查核
  • 發現紀錄不一致時即時提醒
  • 建立常見錯誤案例提醒
🚀 執行方式：發現異常 → 通知 → 修正 → 再確認

📈 CHECK / ACT｜成效追蹤

  • 每月追蹤收案完整率
  • 比較改善前後未達標個案
  • 評估是否仍有重複發生
  • 穩定後納入標準 QC 流程
📊 追蹤指標：Redcap 收案完整率

② 呼吸照護紀錄之完整性與品質

Flow sheet、Progress note、Weaning profile 與 Biweekly 紀錄追蹤

📝 PLAN｜問題確認

發現部分呼吸照護紀錄未依規範完成， 包括 Weaning profile 判讀及 Biweekly 紀錄完整性。

  • 判讀與紀錄流程不一致
  • Biweekly 紀錄可能延遲
  • 個別人員執行差異
🎯 改善目標：提升紀錄完整性與一致性

🚀 DO｜改善措施

  • 宣導 Weaning profile 判讀標準
  • 加強 Biweekly 紀錄提醒
  • QC 例行查核 Flow sheet
  • 針對缺失進行個別回饋
🚀 執行方式：查核 → 提醒 → 補正 → 再追蹤

📈 CHECK / ACT｜成效追蹤

  • 每月追蹤紀錄完成率
  • 分析重複發生缺失
  • 比較改善前後趨勢
  • 未改善項目再次納入 PDCA
📊 追蹤指標：Flow sheet／Progress note 完整率

③ 呼吸器功能完成率與定期保養

Daily Check、定期保養與氧氣濃度測試之持續改善追蹤

📝 PLAN｜問題確認

發現部分定期保養、 氧氣濃度測試或呼吸器 Daily Check 未依規範完成。

  • 部分項目未完成
  • 個別執行率未達目標
  • 重複性缺失需持續追蹤
🎯 改善目標：提升功能檢查與保養完成率

🚀 DO｜改善措施

  • 加強 Daily Check 宣導
  • 提醒定期保養時程
  • 加強氧氣濃度測試確認
  • QC 組員複核異常項目
🚀 執行方式：發現缺失 → 確認原因 → 即時改善

📈 CHECK / ACT｜成效追蹤

  • 每月追蹤 Daily Check 完成率
  • 追蹤定期保養完成情形
  • 分析個別未達標原因
  • 持續未改善者重新進行 PDCA
📊 追蹤指標：Daily Check 與定期保養完成率

🔄 Next PDCA Cycle
